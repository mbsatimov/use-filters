This page builds a small filtered list from start to finish. You need the nuqs
adapter [mounted](/docs/installation#mount-the-nuqs-adapter) before any of it
works.

## Try it

This is the real hook. Type in the box or pick a status, and watch the address
bar and the `params` object change together. They are both read from the URL.

## Declare your filters

Pass `useFilters` an object of `key: f.*()` pairs. Each key becomes a query param
and a key on `params`. The builder (`f.text`, `f.select`, …) decides how the value
is parsed.

```tsx
import { f, useFilters } from '@mbsatimov/use-filters';

const statusOptions = [
  { label: 'Open', value: 'open' },
  { label: 'Closed', value: 'closed' }
];

function ProductsPage() {
  const { params, filters } = useFilters({
    search: f.text({ label: 'Search' }),
    status: f.select({ label: 'Status', valueType: 'string', options: statusOptions })
  });

  // ...
}
```

## Fetch with `params`

`params` here is `{ search, status, page, per_page }`. Send it to your API and use
it as the query key, so a filter change refetches:

```tsx
const { data } = useQuery({
  queryKey: ['products', params],
  queryFn: () => productApi.getAll(params)
});
```

<Callout>
  `params` only changes when the URL does, so it works as a cache key for React Query, SWR or a
  plain `fetch` without any extra dependency array.
</Callout>

## Render your filters

`filters` is an array with one entry per filter: your config plus the current
`value` and an `onChange`. Render it however you like. With plain HTML controls:

```tsx
import type { ResolvedFilter } from '@mbsatimov/use-filters';

function Toolbar({ filters }: { filters: ResolvedFilter[] }) {
  return filters.map((filter) => {
    if (filter.type === 'text') {
      return (
        <input
          key={filter.key}
          placeholder={filter.label}
          value={filter.value ?? ''}
          onChange={(e) => filter.onChange(e.target.value || null)}
        />
      );
    }

    if (filter.type === 'select') {
      return (
        <select
          key={filter.key}
          value={filter.value ?? ''}
          onChange={(e) => filter.onChange(e.target.value || null)}
        >
          <option value=''>{filter.label}</option>
          {filter.options.map((option) => (
            <option key={option.value} value={option.value}>
              {option.label}
            </option>
          ))}
        </select>
      );
    }

    return null;
  });
}
```

That covers the basics: declare the filters, fetch with `params`, render `filters`.

## Install

Install the package with its two peer dependencies, `react` (18 or 19) and
[`nuqs`](https://nuqs.dev) (2 or later):

```bash
npm install @mbsatimov/use-filters nuqs
# or: pnpm add / yarn add / bun add
```

## Mount the nuqs adapter

The state lives in the URL through nuqs, and nuqs needs its adapter mounted once
at the root of your app. That's the only setup. Without it, `useFilters` throws.
Use the adapter for your router:

<Tabs items={['Next.js (App)', 'Next.js (Pages)', 'React Router', 'Remix', 'Plain React']}>

```tsx tab="Next.js (App)"
// app/layout.tsx
import { NuqsAdapter } from 'nuqs/adapters/next/app';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <NuqsAdapter>{children}</NuqsAdapter>
      </body>
    </html>
  );
}
```

```tsx tab="Next.js (Pages)"
// pages/_app.tsx
import { NuqsAdapter } from 'nuqs/adapters/next/pages';

export default function App({ Component, pageProps }) {
  return (
    <NuqsAdapter>
      <Component {...pageProps} />
    </NuqsAdapter>
  );
}
```

```tsx tab="React Router"
import { NuqsAdapter } from 'nuqs/adapters/react-router/v7';

<NuqsAdapter>
  <RouterProvider router={router} />
</NuqsAdapter>;
```

```tsx tab="Remix"
import { NuqsAdapter } from 'nuqs/adapters/remix';

<NuqsAdapter>
  <Outlet />
</NuqsAdapter>;
```

```tsx tab="Plain React"
import { NuqsAdapter } from 'nuqs/adapters/react';

<NuqsAdapter>
  <App />
</NuqsAdapter>;
```

</Tabs>

nuqs also has adapters for TanStack Router and others; see the
[nuqs adapter docs](https://nuqs.dev/docs/adapters).
